# Collective Studios Australia — Website Prototype

A deployable static website concept for Collective Studios Australia.

## Deploy
Upload this folder to Netlify, Vercel, Cloudflare Pages, GitHub Pages, or any standard web host.

For Vercel: create a new project from a Git repository containing these files. No build command is required; serve `index.html` as a static site.

## Before launch
1. Confirm final registered brand/domain.
2. Replace `hello@collectivestudios.com.au` with the live enquiry address.
3. Replace abstract artwork with approved photography/showreels if desired.
4. Confirm wording and permission for each tenant listing.
5. Add final Instagram, LinkedIn and Vimeo URLs in the footer.
6. Connect the enquiry form to Formspree, HubSpot, Webflow Forms, a serverless endpoint, or your preferred CRM rather than `mailto:`.
7. Add privacy policy / terms and analytics consent as required.
